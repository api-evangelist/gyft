# Gyft

> Gyft is a digital gift card platform (a Fiserv / First Data company) for buying, sending, storing, and redeeming digital gift cards from 250+ retail brands. For businesses it offers the Gyft API and Gyft SDK to add digital gift cards to apps, websites, employee rewards, and incentive programs, plus bulk corporate ordering through Gyft Business.

This llms.txt was generated by the API Evangelist enrichment pipeline from apis.yml and the provider's public developer surface. The Gyft developer documentation sits behind a bot-protection layer (ShieldSquare), so operation-level detail is not machine-fetchable; the API and SDK are provisioned to enrolled partners.
